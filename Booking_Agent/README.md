# Booking Agent (티켓 예매 자동화 봇)

Booking Agent는 Playwright와 Electron을 기반으로 제작된 **반자동 웹 크롤러 및 결제 보조 데스크톱 애플리케이션**입니다.

## 기능 (Features)
- **인터파크 예매 자동화 지원**: 대상 사이트 접속 후 로그인 상태를 감지, 예매 버튼 활성화를 감시(Backoff 적용)하고 클릭합니다.
- **실제 좌표 기반 좌석 선택**: Playwright의 boundingBox를 통해 화면상 Y좌표(위/아래)를 분석하여 사용자가 선호하는 좌석(앞/중간/뒤)을 자동으로 선택합니다.
- **반자동화 흐름**: 봇 차단이나 결제 보안 이슈를 피하기 위해 결제는 자동화 완료 후 사용자가 직접 수행하도록 설계되었습니다(Semi-Automation).
- **디자인 패턴 적용**: Facade, Strategy, Factory 패턴을 적용하여 새로운 예매 사이트 추가 및 유지보수가 매우 용이합니다.

## 지원 사이트 상태
현재 인터파크(Interpark)의 기본적인 자동화 플로우가 구현되어 있습니다. 나머지 사이트들은 보안 이슈 및 복잡한 흐름으로 인해 현재 미지원(NotImplemented) 상태로 수동 예매를 권장합니다.

## 설치 및 실행 방법

### 개발 환경 설정
Node.js가 설치되어 있어야 합니다.
\`\`\`bash
cd Booking_Agent
npm install
npm run start 명령어 실행(터미널 백그라운드 등)
\`\`\`

### 배포용 빌드
일반 사용자를 위해 실행 파일로 패키징할 수 있습니다.
\`\`\`bash
npm run dist
\`\`\`
빌드가 완료되면 `dist/` 폴더 내에 빌드된 파일이 생성됩니다.
**주의사항**: Windows에서 코드 서명이 적용되지 않은 `.exe` 파일을 실행할 경우, Windows SmartScreen 경고가 표시될 수 있습니다. "추가 정보" -> "실행"을 클릭하여 진행할 수 있습니다.
