# Booking Agent (티켓 예매 자동화 봇)

Booking Agent는 Playwright와 Electron을 기반으로 제작된 **반자동 웹 크롤러 및 결제 보조 데스크톱 애플리케이션**입니다.

## 기능 (Features)
- **12개 예매 사이트 자동화 지원**: 대상 사이트 접속 후 로그인 상태를 감지(인터파크, 티켓링크, YES24, 멜론 등), 예매 버튼 활성화를 감시(Backoff 적용)하고 클릭합니다.
- **실제 좌표 기반 좌석 선택**: Playwright의 boundingBox를 통해 화면상 Y좌표(위/아래)를 분석하여 사용자가 선호하는 좌석(앞/중간/뒤)을 자동으로 선택합니다.
- **반자동화 흐름**: 봇 차단이나 결제 보안 이슈를 피하기 위해 결제는 자동화 완료 후 사용자가 직접 수행하도록 설계되었습니다(Semi-Automation).
- **디자인 패턴 적용**: Facade, Strategy, Factory 패턴을 적용하여 새로운 예매 사이트 추가 및 유지보수가 매우 용이합니다.

## 주의 사항 및 한계점
1. **좌석 선호도(앞/중간/뒤)의 기준**
   - 본 프로그램은 활성화된 좌석 요소들의 **화면상 Y좌표**를 계산하여 정렬합니다.
   - 즉, `Y값이 작을수록(화면 위쪽) = 앞쪽 좌석`이라는 가정하에 동작합니다. 만약 특정 공연의 무대가 화면 아래쪽에 그려진 좌석도라면, "앞쪽(front)"을 선택했을 때 실제로는 가장 뒷좌석이 선택될 수 있으므로 주의가 필요합니다.
2. **Canvas 기반 좌석도 미대응**
   - 대형 예매 사이트(예: 인터파크 대극장 공연 등)에서 사용하는 **Canvas 기반 좌석도**는 DOM(HTML 요소)으로 구성되지 않아 스크립트를 통한 좌표 탐색 및 클릭이 불가능합니다.
   - 프로그램이 명시적인 좌석 DOM 요소를 찾지 못하면, 예매창을 활성화해둔 상태로 에러 로그를 띄우며 중단됩니다. 이 경우 **사용자가 직접 화면을 보고 좌석을 수동으로 선택**하여 예매를 완료해야 합니다.

## 설치 및 실행 방법

### 개발 환경 설정
Node.js가 설치되어 있어야 합니다.
\`\`\`bash
cd Booking_Agent
npm install
npm run start # 명령어 실행(터미널 백그라운드 등)
\`\`\`

### 배포용 빌드
일반 사용자를 위해 실행 파일로 패키징할 수 있습니다.
\`\`\`bash
npm run dist
\`\`\`
빌드가 완료되면 `dist/` 폴더 내에 `mac`, `linux-unpacked`, `win-unpacked` 및 빌드된 실행 파일이 생성됩니다.
**주의사항**: Windows에서 코드 서명이 적용되지 않은 `.exe` 파일을 실행할 경우, Windows SmartScreen 경고가 표시될 수 있습니다. "추가 정보" -> "실행"을 클릭하여 진행할 수 있습니다.
