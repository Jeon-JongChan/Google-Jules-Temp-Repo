# 프로젝트: AI Studio — Google AI 서비스 통합 안드로이드 앱

당신은 숙련된 Android 및 브라우저 엔진 개발자입니다.

**목표는 Google Flow, Google Flow Music, Google Vids의 기존 웹서비스를 하나의 독립형 안드로이드 APK에서 이용할 수 있도록 만드는 것입니다.**

단순한 기획이나 UI 목업이 아니라 실제 Android Studio에서 실행 가능한 프로젝트를 개발하세요.

## 1. 핵심 개발 원칙

- Google의 유료 AI 생성 API를 사용하지 않습니다.
- Google Flow, Flow Music, Vids의 기존 공식 웹 기능을 사용합니다.
- 사용자는 자신의 Google 계정으로 각 서비스에 정상 로그인합니다.
- 서비스의 기존 생성 크레딧과 이용 권한을 그대로 적용합니다.
- Google 서비스의 서버 코드나 비공개 API를 복제하지 않습니다.
- 비공식 API 호출, 인증 우회, 쿠키 탈취, 토큰 추출, 서비스 접근 제한 우회 기능은 구현하지 않습니다.
- microG에 의존하지 않는 구조를 우선합니다.
- 가능하면 세 서비스를 하나의 APK에서 탭으로 전환하도록 구성합니다.
- 기술적으로 불가능하거나 지원되지 않는 기능은 가능하다고 가정하지 말고 원인을 표시합니다.

## 2. 개발 기술

- 언어: Kotlin
- UI: Jetpack Compose + Material 3
- Android: Android 12 이상
- 브라우저 엔진 후보: Mozilla GeckoView
- 웹 UI 커스터마이징: WebExtensions + CSS + JavaScript
- Google 인증이 필요한 경우: Chrome Custom Tabs 또는 공식 외부 브라우저
- 파일 관리: Android Storage Access Framework
- 로컬 프로젝트 관리: Room Database
- 개발 환경: Android Studio + Gradle

모든 라이브러리는 개발 시점의 공식 문서를 확인해 호환되는 안정 버전을 사용하세요.

## 3. 앱 화면 구성

하단에 네 개의 메뉴를 배치합니다.

### A. Flow — AI 영상 생성

공식 Google Flow 웹서비스를 실행합니다.

URL: https://flow.google.com/

요구 기능:
- 기존 Google 계정으로 서비스 이용
- 영상 생성 프롬프트 입력
- 이미지 업로드
- 영상 생성 결과 확인
- 다운로드 및 파일 공유
- 기존 프로젝트 접근

가능한 경우 CSS를 적용해 모바일 화면에 맞는 UI를 구성합니다.

단, 원본 웹사이트 기능을 손상시키지 않아야 합니다.

### B. Flow Music — AI 음악 생성

공식 Google Flow Music 웹서비스를 실행합니다.

URL: https://www.flowmusic.app/

요구 기능:
- Google 계정 로그인
- 음악 생성
- 기존 음악 프로젝트 접근
- 생성 결과 재생
- 음악 파일 다운로드 및 공유
- 생성 음원을 통합 프로젝트 보관함에 추가

### C. Vids — AI 영상 편집

공식 Google Vids 웹서비스를 실행합니다.

URL: https://vids.new/

가장 중요한 개발 목표입니다.

먼저 안드로이드에서 PC용 Google Vids 편집 기능이 실제로 실행 가능한지 확인합니다.

실행된다면 WebExtensions를 이용한 CSS 재구성을 검토합니다.

희망 UI:
- 상단: AI 편집 명령 입력
- 중앙: 영상 미리보기
- 하단: 타임라인
- 접이식 메뉴: 미디어·음악·자막·AI 도구
- 하단 주요 버튼: 저장 및 내보내기

단, CSS 변경만으로 비활성화된 기능을 활성화할 수 있다고 가정해서는 안 됩니다.

Google Vids가 모바일 브라우저의 편집 기능을 차단한다면 우회 코드를 구현하지 말고 기술적 원인을 보고하세요. 지원되는 PC 브라우저로 프로젝트를 전달하는 대체 흐름을 구현합니다.

### D. 프로젝트 보관함

Flow와 Flow Music에서 제작한 파일을 관리합니다.

기능:
- 프로젝트 생성 및 이름 변경
- 영상 파일 가져오기
- 음악 파일 가져오기
- 파일 미리보기 및 재생
- 파일 삭제
- 공유 메뉴에서 파일 수신
- 프로젝트별 미디어 목록 표시
- Vids로 전달할 파일 선택

Android ACTION_SEND, ACTION_SEND_MULTIPLE, ACTION_OPEN_DOCUMENT 등을 활용하세요.

파일 경로 직접 접근에 의존하지 말고 content URI와 Android 저장소 권한 체계를 준수하세요.

## 4. 브라우저 통합 방식

먼저 GeckoView를 이용한 웹사이트 표시 기능을 구현합니다.

공식 Mozilla WebExtensions 기능을 이용하여 허용되는 웹페이지에 CSS와 JavaScript를 적용할 수 있게 구성하세요.

다음 기능을 구현합니다.

- 서비스별 브라우저 세션 관리
- 탭 전환
- 페이지 로딩 표시
- 새로고침
- 뒤로 가기
- 파일 다운로드
- 업로드 파일 선택기
- 팝업 및 외부 링크 처리
- 로그인 실패 및 미지원 브라우저 오류 안내

중요 사항:
- Google OAuth 로그인 화면에 JavaScript를 주입하지 않습니다.
- Google 로그인 페이지의 쿠키나 토큰을 수집하지 않습니다.
- 로그인이 차단되면 Chrome Custom Tabs를 사용합니다.
- Custom Tabs에서는 외부 웹페이지 CSS 직접 수정이 불가능하다는 제약을 반영합니다.
- Google 서비스의 계정 이용 권한과 사용량 제한을 존중합니다.

## 5. 모바일 CSS 모듈

공식 웹사이트가 실제로 로드되고 해당 방식이 허용되는 경우에만 작동하는 모듈을 개발합니다.

목표:
- PC 레이아웃을 모바일 화면에 맞게 배치
- 큰 사이드바를 접이식 메뉴로 변경
- 작은 버튼의 터치 영역 확대
- 화면 가로 넘침 최소화
- 영상 미리보기 영역 최적화
- 타임라인 가로 스크롤 개선
- 원래 웹서비스의 이벤트와 기능 유지

서비스별 CSS를 독립 파일로 관리합니다.

웹사이트 DOM 구조가 변경되면 CSS를 비활성화할 수 있는 안전장치를 구현합니다.

## 6. 사용자 경험

- 다크 모드 기본 지원
- 한국어 인터페이스
- 하단 탭 메뉴
- 프로젝트 자동 저장
- 오류 발생 시 복구 기능
- 서비스별 접속 상태 표시
- 파일 공유 및 가져오기 안내

별도 AI 서버는 구축하지 않습니다.

## 7. 단계별 개발 및 검증

### 1단계: 기본 앱

실행 가능한 Android Studio 프로젝트를 생성하고 네 개의 탭과 프로젝트 관리 화면을 구현합니다.

### 2단계: 서비스 연결

Flow, Flow Music, Vids를 실제 웹 주소로 연결합니다. 페이지 로드, 로그인, 서비스 호환성을 검증합니다.

### 3단계: CSS 커스터마이징

정상 작동하는 페이지에 한해 모바일 UI를 수정합니다.

### 4단계: 파일 관리

다운로드한 영상과 음원을 통합 보관함에 가져오고 다른 서비스에서 선택할 수 있도록 구현합니다.

### 5단계: Vids 검증

영상 가져오기, AI 편집, 타임라인, 내보내기를 각각 테스트합니다.

실제 기기 검증이 필요한 항목은 '미검증'으로 명시합니다.

## 8. 반드시 제공할 결과물

1. 전체 Android Studio 프로젝트 소스코드
2. Kotlin 소스 파일
3. Gradle 설정 및 빌드 파일
4. GeckoView 브라우저 모듈
5. WebExtension 및 CSS 파일
6. 프로젝트 및 파일 관리 기능
7. APK 빌드 방법
8. 실기기 테스트 체크리스트
9. 알려진 기술적 제약과 해결 방안
10. 빌드 환경이 준비된 경우 설치 가능한 디버그 APK

코드 일부만 제공하거나 의사코드로 끝내지 마세요.

먼저 실제로 작동하는 최소 기능 제품(MVP)을 구현하고 이후 확장합니다.

**가장 중요한 성공 조건은 Google 서비스를 복제하지 않고, 기존 공식 서비스를 활용하는 독립 안드로이드 앱을 만드는 것입니다.**

인증이나 모바일 기능 지원 문제로 원래 요구사항을 달성하지 못하면 해당 기능을 작동한다고 표시하지 말고, 실제 구현 상태를 정확히 보고하세요.
