# 1. 세계관

## 1-1. 세계 기본 설정

| 항목 | 내용 |
|--------|--------|
| 배경 | 단일 대륙 판타지 |
| 시대 | 중세 + 혼합 (냉병기, 화약 일부, 특수 기술) |
| 마법 | 희귀, 강한 마법사는 국가·성직단이 독점 |
| 통치 | 제국 중심 강력한 중앙집권 |
| 주요 재화 | 제국 금화, 마나석 |
| 신앙 | 신 존재 불명, 종교 영향력 강함 |

## 1-2. 세력 전력도

| 세력 | 전력 | 비고 |
|--------|--------|--------|
| 제국 | 130 | 패권국 |
| 강국 A | 80 | 던전 기술 확보 시도 |
| 강국 B | 70 | 제국 견제 |
| 강국 C | 60 | 국경 분쟁 |
| 소국 | 30 이하 | 다수 존재 |

## 1-3. 역사

고대에 던전이 발견되며 막대한 자원 확보가 가능해졌다.

제국은 던전 소유권 전쟁에서 승리하며 패권국으로 성장했다.

시간이 지나 자원이 고갈되고 몬스터가 강해지면서 외곽 지역은 방치되기 시작했다.

## 1-4. 던전 기술 독점

던전의 세부 원리와 고급 활용법은 제국 고위층이 독점한다.

# 2. 던전 시스템

## 2-1. 던전의 정체

던전은 고대 문명의 차원 에너지 채굴장이다.

현재는 폭주 상태이며 몬스터 생성 장치가 되었다.

| 항목 | 내용 |
|--------|--------|
| 본질 | 차원 에너지 채굴장 |
| 입구 | 포탈 |
| 내부 환경 | 몬스터 특성에 따라 자동 생성 |
| 생성 코어 | 심층부 존재 |
| 원리 | 누구도 완전히 모름 |

## 2-2. 공략 사이클

- 방치 시 몬스터 강화
- 보스 처치 시 일시 소멸
- 일정 시간 후 재생성
- 완전 제거 불가능

# 로어 텍스트

왕도의 사람들은 그 땅을 잊었다.

세금 장부에만 이름이 남은 제국의 끝자락.

몬스터가 문을 두드리고,
황무지가 밭을 삼키고,
용병들은 죽거나 도망쳤다.

그리고 왕자가 왔다.

아무도 원하지 않아서,
아무도 빼앗지 않은 그 자리에.

여기서 무언가가 시작된다.

그것이 전설인지,
비극인지,
아직 아무도 모른다.
