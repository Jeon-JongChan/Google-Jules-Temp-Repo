# 에셋 추가 계획 (Assets Plan)

현재 프로토타입 1차 버전(기획서 v0.4 기반)에서는 핵심 시스템 구현에 집중하고 있으므로, 부가적인 멀티미디어 에셋은 포함하지 않습니다.

- **오디오 (효과음/배경음)**: 게임 루프(전투/영지 경영)가 확정된 이후, 2차 프로토타입 단계에서 적절한 에셋을 선정하여 추가할 예정입니다.
- **폰트 (한글 폰트)**: 현재는 시스템 기본 폰트에 의존하고 있습니다. UI 다듬기 단계에서 게임 분위기에 맞는 라이선스 프리(License-free) 한글 폰트를 탐색하여 일괄 적용할 예정입니다.
