# 기획 문서

기획자가 전달한 문서를 이 폴더에 둡니다. 개발 시 AI·팀원이 여기를 먼저 참고합니다.

## 넣기 좋은 문서

- GDD (게임 디자인 문서)
- 시스템 기획 (전투, 인벤토리, 퀘스트 등)
- 레벨·월드 구성
- UI/UX 와이어프레임 설명
- 밸런스·수치 표

## 파일 형식

| 형식 | 개발·AI 참고 |
|------|----------------|
| `.html` | UI 목업·와이어프레임에 적합 — 구조·레이아웃·텍스트 읽기 가능 |
| `.pdf` | 가능 — 텍스트 선택되는 PDF가 유리. 스캔 이미지 위주면 해석이 어려울 수 있음 |
| `.md` | 수치·플로우·요약 정리용으로 좋음 |
| `.png`, `.jpg` | UI 캡처·목업 이미지 |

PDF·HTML만으로도 충분히 사용 가능. 다만 **화면 이름·수치·상태 전이**처럼 자주 참조하는 내용은 짧은 `.md` 메모를 곁들이면 개발이 더 빠르다.

## 폴더 예시 (PDF + HTML UI)

```
docs/design/
├── ui/
│   ├── main-menu.html      # UI 목업
│   ├── inventory.html
│   └── hud-layout.pdf
├── systems/
│   └── combat-balance.pdf
└── ui-index.md             # (선택) 화면별 파일 경로·핵심 수치 요약
```
